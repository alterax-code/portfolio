7. CARROUSEL EN VANILLA JS
Pour la version vanilla, le carrousel est implemente en pur CSS + JavaScript, sans librairie externe.
7.1 Structure HTML du carrousel
<div class="carousel-container">
<button class="carousel-arrow carousel-prev">&#10094;</button>
<div class="carousel-viewport">
<div class="carousel-track">
<div class="carousel-card">...contenu carte 1...</div>
<div class="carousel-card">...contenu carte 2...</div>
<div class="carousel-card">...contenu carte 3...</div>
</div>
</div>
<button class="carousel-arrow carousel-next">&#10095;</button>
<div class="carousel-dots"></div>
</div>
7.2 Principe CSS
• carousel-viewport : overflow: hidden, width: 100%
• carousel-track : display: flex, transition: transform 0.5s ease
• carousel-card : min-width: 100% (mobile), 50% (tablette), 33.33% (desktop)
• Navigation : Le JS modifie le transform: translateX() du track pour slider
7.3 Principe JS
• Variable currentIndex pour suivre la position
• Les fleches incrementent/decrementent currentIndex
• Le nombre de cards visibles change selon la largeur (window.innerWidth)
• Swipe tactile : touchstart/touchend pour detecter la direction
• Les dots sont generes dynamiquement selon le nombre de 'pages'
• Loop : quand on depasse la derniere carte, revenir a 0

9. INTERNATIONALISATION (FR/EN) EN
VANILLA
Approche simple : chaque element de texte a deux attributs data (data-fr et data-en). Un bouton dans
la navbar toggle entre les deux langues.
9.1 HTML
<!-- Bouton dans la navbar -->
<button id="lang-toggle" class="lang-btn">EN</button>
<!-- Textes traduisibles -->
<p data-fr="Developpeur Full Stack & Data Science"
data-en="Full Stack Developer & Data Science">
Developpeur Full Stack & Data Science
</p>
9.2 JavaScript
let currentLang = 'fr';
document.getElementById('lang-toggle').addEventListener('click', () => {
currentLang = currentLang === 'fr' ? 'en' : 'fr';
document.querySelectorAll('[data-fr]').forEach(el => {
el.textContent = el.getAttribute('data-' + currentLang);
});
document.getElementById('lang-toggle').textContent =
currentLang === 'fr' ? 'EN' : 'FR';
});
